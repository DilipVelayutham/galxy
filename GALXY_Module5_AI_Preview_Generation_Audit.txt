3.1 Routing Infrastructures (Public & Administrative Segregation)
• File Verification - admin_ai_routes.py: The administrative path layer is now fully established. It encapsulates the GET /api/admin/ai/generations route, allowing historical aggregation and filtering by category, execution timestamp, or outcome status without polluting public-facing customer endpoint definitions.• Single-Source-of-Truth Enforcement: Inspection must confirm that the category write endpoint (PUT /api/admin/categories/:id/ai-prompt-template) remains exclusively owned by Module 2. Our module must restrict itself to a read-only role, averting data synchronization anomalies.
3.2 app/services/prompt_builder_service.py (Natural Language Synthesis)
1. Attribute Label Processing: Confirm that variable parsing logic extracts the clear, natural-language label (e.g., 'Cursive', 'Bold') instead of internal snake_case database keys ('cursive_v1', 'bold_v2') so prompts sent to the Gemini API read naturally.2. Optional Variable Fallbacks: When an optional configuration property is omitted by the user, the builder must replace the target curly-brace placeholder with an empty string ('') and automatically sanitize stray multi-spaces or broken punctuation.3. Prompt Injection Defense: Verify that user text inputs (custom_text) undergo robust filtering to block prompt injection phrases ('ignore previous instructions', 'override safety parameters') before rendering.
3.3 app/services/ai_cache_service.py (Global Cost Controls)
CRITICAL EDGE-CASE WARNING | Critical Security Requirement: Cache instances are stored globally across the platform to maximize efficiency for default selections. As an absolute rule, the cache engine must completely bypass lookup and storage operations if a configuration payload contains a 'custom_text' field. Failing to bypass the cache on user text will cause User B to see a cached asset containing User A's custom typed names or private identifiers.

3.4 app/services/ai_rate_limit_service.py (Quota & Response Structuring)
• Cache Quota Protection: Verify that a successful cache match short-circuits the workflow and skips quota deduction steps. Only live downstream AI provider calls should decrease a guest session or logged-in user's allocation pool.• API Payload Contract Stability: Under guest session limit states, the service must produce an HTTP 429 response matching the front-end specification: {"success": false, "message": "...", "data": { "limit_reached": true } }. The front-end design system relies on the limit_reached flag to trigger the contextual signup prompt.
3.5 app/utils/cloudinary_helper.py (Asset Isolation)
• Directory Segregation: The media helper must pass an explicit folder destination parameter (e.g., 'galxy/ai-previews/') during asset uploads. AI-rendered images must remain separate from standard catalog product photos to ensure administrative cleanup jobs can safely run without impacting permanent business assets.
