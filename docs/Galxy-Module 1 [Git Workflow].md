## 12. Git Command Reference

| Command             | Purpose                 |
| ------------------- | ----------------------- |
| git clone           | Clone repository        |
| git fetch origin    | Fetch remote updates    |
| git switch <branch> | Switch branch           |
| git pull            | Download latest commits |
| git status          | Check repository state  |
| git add .           | Stage changes           |
| git commit -m       | Create commit           |
| git push            | Upload commits          |
| git branch -a       | List branches           |
| git log             | View history            |
| git diff            | View changes            |
| git stash           | Temporarily save work   |
| git restore         | Restore files           |

## 13. Golden Rules

1. Work only on your assigned branch.

2. Pull before you start coding.

3. Commit small logical changes.

4. Use meaningful commit messages.

5. Never push directly to dev or main.

6. Never modify another intern's code without approval.

7. Test before every push.

8. Create a Pull Request for every completed task.

9. Never merge your own Pull Request.

10. Keep documentation updated.
